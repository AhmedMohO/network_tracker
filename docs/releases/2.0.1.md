# NetTrack 2.0.1

## Choose which Wi-Fi usage counts toward your limit

The Wi-Fi limit bar and its settings dialog now let you choose **all Wi-Fi networks** or one recorded network. The choice is saved, and the bar, usage forecast, and Wi-Fi alerts follow it. Your existing shared Wi-Fi limit amount is preserved, including fractional limits.

## More reliable usage and history

- Wi-Fi network totals now reconcile with Android's summary totals. Missing bucket bytes are shown as unattributed instead of disappearing from the archive.
- Archive recovery covers the full 80-day live-history window. Incomplete snapshots are retried, and successful empty days are recorded explicitly.
- Refreshing history protects saved bytes and previously recorded Wi-Fi names.
- Wi-Fi recording handles clock changes, unreadable network names, observation gaps, and concurrent reads and writes more safely.
- New archives retain foreground/background usage. Older records without that information show it as unavailable.
- Partial archived days are clipped and labeled as estimates. Charts include partial periods and stop at the requested end.
- Updated English/Arabic labels and version information.

## Updating

Install **NetTrack-v2.0.1.apk** over your existing NetTrack installation. **Do not uninstall NetTrack or clear its data first.** Open the updated app once so recoverable archive days can be repaired.

## Limits to keep in mind

- Named-network usage is estimated, requires Wi-Fi Network Attribution, and excludes unattributed bytes. Networks sharing the same Wi-Fi name are combined.
- Detail already removed from Android's history cannot be reconstructed.
- Regular family synchronization remains available. Instant updates that wake a sleeping phone are not enabled in this release.
