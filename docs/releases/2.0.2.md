# NetTrack 2.0.2

## More reliable Wi-Fi tracking — no VPN required

- Disconnected Wi-Fi cannot reuse a cached network name. Ambiguous connections remain unattributed.
- Stopping tracking closes its session immediately; late callbacks cannot restart it.
- Process restarts preserve gaps in observation instead of extending the previous network through them.
- Network changes request readable Wi-Fi names on supported Android versions, subject to your existing permissions.
- Integer allocation conserves small and large byte counts. Archived network shares remain marked as estimates.

## Usage, background work, and family repairs

- Preserve download/upload totals in compressed family history and show unavailable older breakdowns honestly.
- Resume daily family backfill after offline gaps; remove a child device without deleting its family.
- Keep archived traffic when Android reassigns an uninstalled app's usage.
- Respect the background-sync switch and improve foreground-app lifecycle tracking.
- Existing usage history, settings, Wi-Fi limits, exports, and family pairing formats are retained.

## Updating and signing-key migration

This release rotates the signing certificate because the previous signing key was exposed in repository history.

- **Android 9 and newer:** install **NetTrack-v2.0.2.apk** over the existing app. It contains the verified signing lineage needed to retain app data during the certificate change. **Do not uninstall NetTrack or clear its data.**
- **Android 7/8 with NetTrack already installed:** Android cannot securely rotate an installed app's signing certificate on these versions. Keep your existing installation and its data; this release does not provide an in-place update for it.
- **Fresh installations on Android 7/8:** extract the APK from **NetTrack-v2.0.2-fresh-install-android7.zip**. This is a fresh-install package, not a migration for an old-key installation.

Open the updated app once to resume background work. Wi-Fi attribution remains optional and requires the existing location permissions; it does not require a VPN.
